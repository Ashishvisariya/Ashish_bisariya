## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/Ashishvisariya/<repository-name>.git
```

Navigate to the project:

```bash
cd <repository-name>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The portfolio will be available at the local development URL shown by Vite.

## 🏗️ Build for Production

```bash
npm run build
```

The production-ready files will be generated in:

```text
dist/
```
